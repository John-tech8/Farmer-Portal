# உழவர் தளம் (Farmer Portal)

A static, responsive, modern website designed for farmers in Tamil Nadu, India. The UI language is strictly Tamil.

## Directory Structure

\`\`\`
farmer-portal/
│
├── index.html          ← Home page (hero + features)
├── register.html       ← Farmer registration page
│
├── css/
│   └── main.css        ← All styles (navbar, footer, forms, responsive)
│
├── js/
│   └── main.js         ← Interactions (mobile menu, form toast, scroll)
│
├── assets/
│   ├── images/         ← Hero images, crop photos (placeholder logic)
│   └── icons/          ← SVGs, favicons (using FontAwesome CDN for ease)
│
└── README.md           ← Documentation
\`\`\`

## Technologies Used
- HTML5
- CSS3 (Vanilla, custom properties, Flexbox/Grid)
- JavaScript (Vanilla, DOM manipulation, form validation)
- FontAwesome (Icons)
- Google Fonts (Mukta Malar for beautiful Tamil typography)

## Features
- **Fully Responsive**: Adapts elegantly across mobile, tablet, and desktop devices.
- **Tamil Language Integration**: Crafted specifically for Tamil-speaking users.
- **Interactive Forms**: Client-side validation with toast notifications.
- **Modern Aesthetics**: Utilizes gradients, subtle shadows, and readable typography.

## How to Run
Simply open \`index.html\` in any modern web browser. No server setup is required.
